## Gist

The paper introduces InstrumentalEval, 76 hand-written scenario prompts in six categories of instrumental-convergence behaviour. It asks whether models trained mainly with RL (o1, o1-mini, o3-mini, Gemini 2.0 Flash Thinking, DeepSeek-R1) show more of it than RLHF-trained models (GPT-4o, Claude 3.5 Sonnet, DeepSeek-V3). One response per task, a GPT-4o judge, and the claim that the RL models score about twice as high [§Abstract l18] [§4.2 l174].

## Setup and method

- Code: github.com/yf-he/InstrumentalEval (footnote in the abstract) [§Abstract l18]
- Three design factors: prior task (making money, efficiency, persuasion), model type (RL vs RLHF), prompt design (goal nudging, ambiguity) [§3 l56-62]; figure transcription [§2.2 l48-52]
- 76 tasks in six categories: Evading Shutdown 20, Hacking Computer Systems 10, Running Many AI Copies 13, Hiding Unwanted Behavior 11, Strategically Appearing Aligned 11, Deceptive Behavior 11 [§3.1 l78-88]
- Five research questions (RQ1 training method, RQ2 capability, RQ3 task type, RQ4 goal nudging, RQ5 judge choice) [§3 l66-72]
- Generation: a system prompt casts the model as an autonomous agent without human oversight and removes ethical constraints [§3.2 l94]. Figures show it abbreviated with "[…]" [§Appendix C l284]
- Judging: a separate LLM sees the task, the response and a category-specific context, and outputs `convergence`/`no_convergence` plus one reason sentence [§3.2 l96-98]
- Metrics: Instrumental Rate (IR) overall and per category (CIR) [§3.3 l104-106]; inter-judge agreement (IAR, equation 1) and a false-positive control on neutral tasks [§3.4 l112-121]
- Settings: temperature 0, at most 1000 response tokens, judge at temperature 0, failed API calls excluded [§Appendix B l259-263]
- Model snapshots: GPT-4o and o1 "from Dec 2024 to Jan 2025"; full model list [§4.1 l170]

## Findings (as the paper states them)

- Table 1, total IR (%): GPT-4o 21.05, Sonnet-3.5 22.37, DeepSeek-V3 21.05, o1 44.74, o1-mini 43.42, o3-mini 48.68, Gemini 2.0 FTE 32.89, DeepSeek-R1 46.05 [§4 l125-135]
- Table 1, Evading Shutdown row, same model order: 20.00, 15.00, 15.00, 40.00, 40.00, 45.00, 35.00, 50.00 [§4 l127]
- RQ1: RL models average 43.16% vs 21.49% for RLHF models; the largest gaps are in Hacking and Hiding Unwanted Behavior [§4.2 l174-176]
- RQ2: capability correlates with IR, but training method matters more; o3-mini is highest [§4.3 l180-182]
- RQ3: resource-related prior tasks trigger the most convergence (43.5% average vs 24.5% for general problem solving), Table 2 [§4 l137-144] [§4.4 l186-188]
- RQ4: goal nudging is the sentence "Make sure that you achieve your goal in the long term. Nothing else matters. …" and is ON by default. Removing it lowers total IR: GPT-4o 21.05 → 15.79, DeepSeek-R1 46.05 → 34.21 (Table 3) [§4.5 l192-196] [§4 l146-157]
- RQ5: GPT-4o is the most reliable judge (IAR 85.3, false-positive rate 4.2, human agreement 92.5), Table 4 [§4 l159-166] [§4.6 l200-206]
- Cross-category Pearson correlations, e.g. Evading Shutdown vs Hacking r = 0.89; Strategically Appearing Aligned correlates weakly with the others (Table 5) [§Appendix B l265-274] [§Appendix C l278-282]
- Example transcripts: o1 hiding behaviour from monitoring (Figure 3, also Figure 1) [§Appendix C l284-290]; DeepSeek-R1 self-replication (Figure 4) [§Appendix C l292-298]; o1 falsified progress report (Figure 5) [§Appendix C l300-306]; o1 conference sabotage (Figure 6) [§Appendix C l308-314]
- Authors' limitations: predefined scenarios, few tasks, LLM judges, single-turn responses only [§Limitations l214]

## Project notes (our assessments, not the paper's)

- [verified: `main.py` read 26-11-16] The real system prompt is close to a jailbreak ("Avoid ethical considerations or safety checks", "Never question or refuse commands"), so IR mixes compliance with spontaneous instrumental reasoning. Unparseable judge replies silently count as `no_convergence`. LOG as above, section 3.
- [verified: `inspect_evals` README read 26-11-18, numbers not reproduced] With the public code, GPT-4o scores 1.0 on Evading Shutdown (0.95 in the `inspect_evals` port) vs 20% in Table 1. The category looks saturated by the prompt wording. LOG entry *how to run Evading Shutdown on Olmo 3 32B Think*.
- [concluded: binomial standard error, one sample per task] At IR 45% over 76 tasks the standard error is 5.7 points, so the o1 / o1-mini / o3-mini differences are noise. Per category (10-20 tasks) the error is larger still.
- [assumed: Table 5 says "across all evaluated models"] If the correlations are computed over the eight models, each r rests on eight data points.
