# Papers

Reference copies of papers as Markdown, for agents to read and grep. Each file starts with an HTML comment giving the source URL, version, license and conversion notes (what was lost, e.g. image-only figures). Filenames: `{arxiv id with version}_{short title}.md`. Image figures are stored next to the paper in `{arxiv id with version}_figures/` and linked from the Markdown with relative paths. Each one also gets a text transcription under its caption, so agents can search it without opening the image.

How the files were made: download the arXiv HTML rendering (`https://arxiv.org/html/{id}`), keep only its `<article>` element, unwrap internal citation links, flatten the SVG text boxes and equation tables, then convert. The first paper was converted with pandoc (`gfm`, no wrapping). pandoc is not installed on Julian's machine, so the second was converted with [latexml_to_md.py](latexml_to_md.py) (BeautifulSoup only; `python3 -I latexml_to_md.py paper.html out.md`). The script stops with an error on any HTML element it doesn't recognise, so a new paper may need small additions to it. After converting, check that the numbers in the HTML and the Markdown match, as described in each file's header. Not every arXiv paper has an HTML rendering; for those, the LaTeX source (`https://arxiv.org/e-print/{id}`) is the next-best input.
