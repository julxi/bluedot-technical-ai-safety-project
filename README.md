## Current status and goals

- Direction chosen (26-11-22): replicate and/or discuss arXiv 2610.31624, which reports that RLVR lowers instrumental convergence in Olmo 3; findings beyond it welcome, no plain reproduction planned. First trend result (26-11-23, course-exercises topic): with full-length replies and a Phi-4 judge, the SFT → DPO rise of arXiv 2610.31624 replicates, but the final checkpoint does not fall below SFT. Since 26-11-26 the same holds with six judge models (Phi-4, four Mistral models, DeepSeek V4.1 Flash) and both prompts: final is never below SFT. Since 26-11-26 also with the paper's own judge (GPT-4o) on six checkpoints (SFT, DPO, steps 200/800/1375, final): no decline over RLVR, final 38.2% vs SFT 34.7% (paper 11.8 vs 25.0). Tentative (no human labels, one reply per task); next: blind labels on the items the judges split on, more replies per task.
