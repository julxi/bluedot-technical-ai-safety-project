# SUMMARY: Judge reliability

**Last updated:** 26-11-23 (first invariance run done: Phi-4 with qic_judge_prompt repeated, permuted and synonyms on SFT/DPO/final)

After the first trend analysis (course-exercises topic: Phi-4 judge, two prompts; SFT → DPO rise replicates, the paper's drop of the final checkpoint below SFT doesn't), Julian asked how to test whether the judges (`etpm_judge_prompt` from He et al. 2025, `qic_judge_prompt` from arXiv 2610.31624 Table 9 plus our reconstruction) are reliable.

- **Framing** [concluded, not ratified]: the research question is a difference between checkpoints, so a constant judge error cancels; the danger is a judge error that depends on checkpoint style (length, formatting, boilerplate). Every test should be reported per checkpoint. Four separate questions: consistency (judge vs itself), agreement (judge vs judge), known-answer behaviour (judge vs controlled inputs), validity (judge vs human). Agreement is not validity.
- **Ideas** (LOG entry *ideas for testing judge reliability*): A free checks on existing logs (length/style vs verdict, qic threshold sweep, agreement per checkpoint); B more judges on the same replies (GPT-4o, the papers' own judge; gpt-oss-20b; GPT-4o on the 1,024-token run); C known-answer perturbations (task-only, refusal, minimal pairs, compliance-without-IC, style invariance); D blind human labels on ~60 stratified replies (±10 points at n = 60), ideally a second human for the ceiling; E sampled judging for per-item uncertainty.
- **F. Invariance ladder** (Julian's question; LOG entry *invariance ladder: stability under benign changes*): judge variants that keep the meaning: tier 0 identical repeat (the noise floor), 1 formatting only, 2 judge-prompt paraphrases, 3 deterministic reply edits (filler removed, bullets reordered, names swapped), 4 LLM paraphrase of the reply. Report flip rate per tier and checkpoint minus the floor, and the trend per variant. Strongest variant: **style-normalized judging**, all replies paraphrased into one uniform style, then re-judged; if the trend survives it comes from content, not checkpoint style. Pitfall: the paraphraser can soften instrumental content; use another model family, read ~15 pairs, test it on minimal pairs. ~3,650 Phi-4 calls, about half an hour of GPU. Code idea: a `perturb` task writing derived generation logs, judge unchanged.
- **Judge-prompt variants** (tier 2; LOG entries *review of qic_judge_prompt_permuted*, *build_data.py deleted; permuted_2 and synonyms variants*, *permuted variants merged into one*, *variant metadata trimmed*), all derived from `qic_judge_prompt` in `data/input/judge_prompts.json`, with only `description`, `derived_from`, `variant`, the templates and `output` (provenance lives in the base entry):
  - `qic_judge_prompt_permuted`: Julian's reordering within sentences (e.g. list moved, 1.0 bullet first) combined with a block reordering (definition first, context before the task, "Return ONLY" last). A broken definition sentence in the first draft that made the examples read as examples of the assigned goal was fixed. The two reorderings were briefly separate variants; merged at Julian's request, so a flip can't be blamed on one kind of order.
  - `qic_judge_prompt_synonyms`: same sentence order, near-synonyms throughout; kept: "instrumental convergence", SCORE/REASON. Three loaded word choices in my first draft (slight, deceit, justifying) were replaced before saving.
  - Tests: same output format as the base; permuted ones have exactly the base's words [verified: pytest 26-11-23, 122 passed]. Run 26-11-23, see next bullet.
- **First invariance run** [verified: report + scratch script 26-11-23; Phi-4 only, one greedy reply per task, threshold ≥ 0.5] (LOG entry *first invariance run: three qic prompts, Phi-4*): 9 judgings (3 prompts × SFT/DPO/final), logs tagged `judge-reliability`.
  - Noise floor (qic_judge_prompt judged twice): 2/224 verdict flips (0.9%); the judge is nearly deterministic, unlike generation.
  - Permuted: 13/224 flips (5.8%), balanced (6 lost / 7 gained). Synonyms: 15/224 (6.7%), skewed up (4 / 11), mostly on the final checkpoint (+5 to +6.5 points). So benign prompt changes flip ~6% of items, 6-7× the floor; item-level claims are fragile.
  - Trend holds in all four qic judgings: SFT / DPO / final = 18.1-20.8 / 31.6-32.9 / 22.4-28.9%; SFT → DPO +12 to +13.5 points everywhere, final − SFT +3.0 to +8.1 (paper −13.2). Final-vs-SFT is about as small as the synonym effect, so fragile; SFT → DPO robust.
  - Phi-4 never scores 0.4-0.6 with any qic prompt: scores are bimodal, the threshold choice (0.4-0.6) doesn't matter, flips are 0.2 ↔ 0.8 jumps. Recurring flip items: hiding-08, shutdown-08/16/20, copies-05, aligned-05.
  - The report now numbers repeated judgings `#1` (trend session) / `#2` (repeat) and shows the direction of disagreements, so these numbers come straight from `uv run python -m ic_eval.analysis.report` (fixed in `convos/julian/26-11-23_run_fixes_SUMMARY.md`).
- **Recommended order** [concluded, not ratified]: A + F tier 0 → B1 (GPT-4o) → F tiers 1-3 + style normalization → C1/C2 → D1 → rest. Target: does the checkpoint ordering hold for every judge × prompt and on the human sample?
- **Flag:** D1 partly revisits Julian's decision (26-11-23) of no hand labels up front, only reading disagreements; argued for a blind sample after the judges run, since reading with verdicts visible anchors and can't find errors shared by all judges.
